# smart-switch

用小度智能音箱语音关灯。

ESP32 驱动一个 SG90 舵机，模拟人手拨动墙壁开关：收到“关灯”指令后，舵机先拨到关位，
再立即退回待机角度松开开关，因此不影响用户自己手动开关灯。目前只实现“关灯”这一个动作，
“开灯”仍由用户手动完成。

## 工作链路

```
小度音箱 → 巴法云 MQTT → ESP32 → SG90 舵机 → 墙壁开关（关）
                                 ↓
                          状态回报 off
```

## 技术栈

- 硬件：ESP32 devkit、SG90 舵机、5V 独立供电（需与 ESP32 共地）
- 框架：Arduino (ESP32)
- 依赖：ESP32Servo、PubSubClient
- 构建：PlatformIO（`platformio.ini`，环境 `esp32dev`）
- 云端：巴法云 MQTT 设备云（bemfa.com:9501）

## 功能

- 只响应 MQTT 下发的 `off`（兼容 `off#xxx` 格式），收到 `on` 或其他内容直接忽略
- 关灯动作：舵机转到关位拨下开关，随后立即退回待机角度，松开开关不阻碍手动操作
- 动作完成后上报 `off`；3 秒时间窗内丢弃巴法云回推的自身上报消息，避免重复拨动
- 上电即停在待机角度，不做状态同步（开关可能被用户手动拨动，真实状态未知）
- WiFi / MQTT 断线自动重连（5 秒退避）
- 串口调试指令 `off`，便于现场排查

## 角度说明

| 常量 | 数值 | 含义 |
|------|------|------|
| `ANGLE_OFF` | 70° | 关灯位置，舵机压向墙壁开关的“关”侧 |
| `ANGLE_REST` | 85° | 拨完后的待机角度，介于开/关之间，松开开关 |

`ANGLE_REST` 需按实际结构微调：如果待机时仍压住开关或挡住手动拨动，可在 95°～100° 之间调整。

## 硬件接线

| 舵机 | ESP32 |
|------|-------|
| 信号线 | GPIO18 |
| 电源 | 外部 5V（不可由 ESP32 3V3 供电） |
| 地线 | 与 ESP32 共地 |

## 配置

复制 `include/secrets.h.example` 为 `include/secrets.h`，填入自己的 WiFi 账号与巴法云私钥、
主题名（该文件已在 `.gitignore` 中，不要提交）。

## 构建与烧录

```bash
pio run
pio run -t upload
pio device monitor
```
